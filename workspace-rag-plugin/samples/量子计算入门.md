# 量子计算入门

量子计算是利用量子力学原理（叠加、纠缠、干涉）进行信息处理的计算范式。
与传统计算机用比特（bit）表示 0 或 1 不同，量子计算机使用量子比特（qubit）。
一个量子比特可以同时处于 0 和 1 的叠加态，这使得量子计算机在某些问题上具有指数级的并行能力。

## 核心概念

- **叠加（Superposition）**：量子比特可同时处于多个状态的线性组合。
- **纠缠（Entanglement）**：多个量子比特之间的关联，测量其中一个会瞬间影响另一个的状态。
- **量子门（Quantum Gate）**：对量子比特进行的酉变换操作，如 Hadamard 门、Pauli-X 门、CNOT 门。
- **量子退相干（Decoherence）**：量子系统与环境相互作用导致量子态坍缩，是构建量子计算机的主要工程难题。

## 经典算法

Shor 算法可以在多项式时间内分解大整数，威胁 RSA 加密体系。
Grover 算法可以对无序数据库实现平方加速搜索。

## 现状

截至 2025 年，IBM 与 Google 都在推进上千量子比特的超导量子处理器，
量子纠错（QEC）是实现容错量子计算的关键研究方向。
