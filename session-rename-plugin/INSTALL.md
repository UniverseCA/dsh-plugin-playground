# 安装 Session Rename（纯客户端动态 Cordis 插件）

**DSH 动态 Cordis 插件**（非 npm 包），**只有 Client 半边**（无 `host.js`）。
通过 `cordis_define` / `cordis_run` 注入会话。

## 前置条件

- 正在运行、支持动态 Cordis 插件的 **DeepSeek Harness** Web 会话。
- 无需凭据、无需网络。

## 安装步骤

1. **加载 Client 半边** —— `cordis_define`：
   - `plugin.idPrefix`: `srn`
   - `code.client`: [`client.js`](client.js) 的内容
   - **不需要** `code.host`。
   - 注意：该插件在返回对象里声明了 `inject: ['slots', 'sessions']`，因此必须用
     **对象形式**的插件返回（而非裸函数），否则 runner 无法把这几个服务门控开放。
2. **激活** —— 对返回的 `pluginId` + `packageId` 执行 `cordis_run`。
3. **授权** —— 按提示允许。
4. **刷新 / 打开会话** —— 会话头部标题簇旁应有「✏️ 重命名」按钮。

## 使用

- 点「✏️ 重命名」→ 输入框自动带入当前标题。
- 输入新标题，回车或点「保存」→ 设置并钉住标题。
- **「用首条消息命名」**：一次点击，用首条用户消息文本（压行截断到 80 字符）作为标题。

## 验证

- 给一个会话设置自定义标题，刷新 / 换会话再回来 —— 标题保留。
- 设自定义标题后再发消息，标题不应被自动更新覆盖（已 pin）。
- 点「用首条消息命名」，标题立即变成首条消息的截断文本。

## 说明

- **已经 head 有自动命名**：本插件用于手动控制 / 首条消息快速命名；不必与 DSH 的内置
  自动命名器冲突（显式标题优先级更高）。
- **注入范围**：只渲染在拥有该插件的宿主页面；独立新标签页不显示。
- 若「保存」显示「此环境无法重命名」，说明该会话未提供 `sessions` 服务（少见）。
